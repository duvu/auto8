## Detailed Changes

### Multi-tenancy (MVP3)
- `Workspace` model added to Prisma schema; `workspaceId` FK column added to User, Connector, Customer, ProductCatalogue, QuoteTemplate, WebhookEndpoint
- JWT payload now includes `workspaceId`; RbacGuard extracts and sets `request.workspaceId`
- `@CurrentWorkspaceId()` decorator for controller params
- Service-layer `workspaceId` scoping in: UsersService, CustomersService, ConnectorRegistryService, WebhookEndpointService, AnalyticsService

### Billing (go-live-blockers)
- `Subscription` model: 1:1 with Workspace; plan (trial/active/expired), status (trialing/active/cancelled), trialEndsAt, stripeCustomerId/subId, sePayOrderCode
- `BillingService`: createStripeCheckout, handleStripeWebhook, initSePayOrder, confirmSePayTransfer (verify by orderCode in transfer content + amount)
- `BillingGuard`: global APP_GUARD after RbacGuard; skips @Public() + super_admin; throws 403 on expired subscription

### Email (go-live-blockers)
- `EmailService` replaces all nodemailer usage; uses Resend SDK; no-op when RESEND_API_KEY unset; 5 methods: send, sendPasswordReset, sendEmailVerification, sendTeamInvite, sendPortalRevisionNotification

### Auth Extensions (go-live-blockers)
- `register()`: creates Workspace + User(admin) + Subscription(trial 14d) + EmailVerifyToken → sends verify email
- `verifyEmail()`: validates token, sets isEmailVerified=true
- `sendInvite()`: creates InviteToken (7d), sends invite email
- `acceptInvite()`: creates User(quote_operator), marks token used, issues JWT pair

### Analytics (MVP3)
- 5 endpoints: rfq-volume (30d), win-rate (90d), response-time (90d avg hours), top-customers (10), connectors (per-connector stats)
- All workspace-scoped

### Customer Portal (MVP3)
- `MagicLinkToken`: single-use, 24h TTL, tied to Quote
- `PortalService`: createShareLink, revokeShareLinks, getQuoteData (validates token), acceptQuote, rejectQuote, requestRevision
- Public routes (no auth) for token-based access

### Contract Hardening (MVP4)
- All shared types consolidated in `packages/shared/src/index.ts` with ownership policy comment
- Local interface duplicates removed from: analytics.service.ts, customers.service.ts, webhook-endpoint.service.ts, api.ts
- 40-check verify:contracts script

### Sentry (go-live-blockers)
- `instrument.ts` + `SentryInterceptor` for NestJS; `Sentry.setUser()` in RbacGuard
- `sentry.client/server/edge.config.ts` + `withSentryConfig` for Next.js

### Rate Limiting (go-live-blockers)
- Named throttlers: default (60/min), auth (5/5min), public (30/min)
- `@Throttle({ auth: ... })` on login, register, forgot-password
- `@Throttle({ public: ... })` on portal routes

- **Auth flow:** JWT now carries workspaceId; workspace-scoped data queries on all major entities
- **Billing flow:** BillingGuard blocks expired subscriptions globally; Stripe checkout + SePay transfer flows
